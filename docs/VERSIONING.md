# Quy ước phiên bản

Release dùng `vMAJOR.MINOR.PATCH`: MINOR cho chức năng mới, PATCH cho sửa lỗi tương thích và tài liệu. Tag được gắn vào commit đã kiểm tra trên `main`; tag đã công bố được giữ nguyên.

| Phiên bản | Nội dung |
|---|---|
| `v0.1.0` | Sprint 1: tài liệu và demo tĩnh |
| `v0.2.0` | Academic MVP: FastAPI, SQLite, đặt món, quản trị và tài khoản khách |
| `v0.2.1` | Bản sửa thanh điều hướng và chuẩn hóa tài liệu |

B2–B7 là mã bài thực hành. V2–V7.3 là nhãn phát triển nội bộ. Các tên file cũ như `START-V7.3.md` và `deploy/install-v4.sh` được giữ để tương thích với đường dẫn đã sử dụng.

Nguồn đối chiếu trạng thái công bố: [GitHub Releases](https://github.com/s2005on/vnu-food-hola/releases). Nội dung từng phiên bản: [CHANGELOG](../CHANGELOG.md).
